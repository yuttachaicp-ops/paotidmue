1 · แจ้งเตือน

เตือนให้ถูกจังหวะ ไม่ใช่เตือนให้ถี่

  • เรียนเวลาจากพฤติกรรม — ดูว่าปกติกดเสร็จตอนกี่โมง แล้วเลื่อนเวลาเตือนตามเอง
  • รู้ว่าคุณไม่ว่าง — ช่วงรับงานส่งของ/ชั่วโมงเงียบ เก็บไว้รวมส่งทีเดียว
  • บันไดการเตือน 4 ขั้น แล้วหยุด ไม่ตื๊อข้ามวัน
  • น้ำเสียงเปลี่ยนตามสถานการณ์ — สตรีคยาวใช้เสียงชม พลาดวันแรกใช้เสียงปลอบ ไม่ใช้คำตำหนิเลย
  1. 1เตือนเบา ๆ ตามเวลาที่เรียนมา
  2. 2ให้ข้อมูลแทนการเร่ง “เหลือ 9 วัน ต้องเฉลี่ย 4.1 กม./วัน”
  3. 3เสนอทางออก “เอาครึ่งเดียวพอไหม” / “ใช้วันลา 1 วัน”
  4. 4ปิดเงียบ แล้วไปสรุปรวมในรายงานวันอาทิตย์
2 · โครงสร้างหน้าเดียว

เปิดมาแล้วกดได้เลยใน 1 วินาที

  • หน้าแรกคือวันนี้ ไม่ใช่รายการเป้าทั้งหมด เป้าที่ยังไม่ถึงคิวถูกพับเก็บ
  • บันทึกจบในปุ่มเดียว — ติ๊ก / +1 / เลื่อนแถบ ไม่ต้องเปิดหน้าใหม่
  • ทุกปุ่มอยู่ครึ่งล่างจอ กดนิ้วโป้งข้างเดียวได้ตอนยืนรอของ
  • ไม่มีหน้า setting ซับซ้อน — ปรับเป้าได้จากการ์ดนั้นเลย
3 · ความยืดหยุ่น

ออกแบบให้ “พลาดได้” โดยไม่ล้มทั้งระบบ

  • วันลา 4 วัน/เดือน ใช้แล้วสตรีคไม่ขาด เพราะชีวิตจริงมีวันที่ทำไม่ไหว
  • ความถี่แบบหลวม — “3 ครั้ง/สัปดาห์” ไม่ต้องระบุว่าวันไหน
  • แก้เป้ากลางทางได้ ลด/เลื่อน/ซอยย่อย ถือเป็นการปรับแผน ไม่ใช่การล้มเหลว
  • ปุ่มพัก หยุดเตือนโดยไม่ลบข้อมูล กลับมาต่อที่เดิมได้
  • ย้อนบันทึกได้ ลืมกดเมื่อวาน กดย้อนหลังได้ 2 วัน
4 · สรุปผลสร้างแรงใจ

บอกความหมาย ไม่ใช่แค่ตัวเลข

  • เทียบกับตัวเองเสมอ — “ดีกว่าเดือนที่แล้ว 7%” ไม่เทียบกับใคร
  • หาแพตเทิร์นให้ — วันไหนทำได้ดี ช่วงไหนมักหลุด แล้วเสนอให้ย้ายเวลา
  • คาดการณ์ปลายทาง — “จังหวะนี้จะถึงเป้าก่อนกำหนด 6 วัน” เห็นผลของวันนี้
  • อธิบายวันที่พลาด ด้วยบริบท ไม่ใช่ด้วยสีแดง
สเปกเทคนิค

ถ้าจะทำเป็นแอปติดตั้งจริง

  • PWA — เว็บที่กด “เพิ่มไปยังหน้าโฮม” แล้วเปิดเต็มจอเหมือนแอป ไม่ต้องขึ้นสโตร์ อัปเดตเองทุกครั้งที่เปิด
  • แจ้งเตือน — Web Push + Service Worker ทำงานแม้ปิดแอป (Android เสถียร / iOS ต้องติดตั้งลงหน้าโฮมก่อน)
  • ข้อมูล — IndexedDB ในเครื่องเป็นหลัก ใช้งานออฟไลน์ได้ แล้วซิงก์ขึ้น Google Sheets หรือ Supabase ตอนมีเน็ต
  • ตัวเลือกสำรอง — ถ้าอยากให้เตือนผ่าน LINE ด้วย ใช้ Apps Script ยิง LINE Messaging API ตามตารางเวลา
